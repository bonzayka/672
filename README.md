# 🔐 Бот продажи подписки (Telegram, aiogram 3)

> Красивая воронка: выбор языка → тарифы → реквизиты оплаты → квитанция → одобрение админом.

Доступ к каналу выдаётся вручную после одобрения квитанции. Бот собирает, учитывает платежи и показывает статистику.

## ✨ Возможности

- 🌐 **Двуязычность** — RU / EN с переключением в один тап
- 💳 **Воронка оплаты** — тарифы → реквизиты → квитанция → проверка
- 👑 **3 тарифа** — неделя, месяц, навсегда (легко добавить новые)
- 📊 **Админ-панель** — статистика, активные подписки, история платежей
- 👤 **Профиль юзера** — команда `/profile` показывает статус подписки
- 📋 **Копирование реквизитов** — кнопка в один тап
- 🎨 **Красивое оформление** — HTML-разметка, эмодзи, разделители

## 🚀 Установка

Python 3.12+:

```bash
pip install -r requirements.txt
```

## ⚙️ Настройка (config.py)

Все настройки в [config.py](config.py):

| Константа | Что это |
|---|---|
| `BOT_TOKEN` | Токен от @BotFather |
| `ADMIN_IDS` | ID админов (через запятую) |
| `STICKER_FILE_ID` | Стикер на /start (необязательно) |
| `PAYMENT_DETAILS` | Реквизиты карты |
| `TARIFFS` | Список тарифов |

## ▶️ Запуск

```bash
python bot.py
```

## 📱 Команды бота

| Команда | Описание |
|---|---|
| `/start` | Начать / купить подписку |
| `/profile` | Посмотреть свою подписку |
| `/id` | Узнать свой Telegram ID |
| `/help` | Справка |
| `/admin` | Панель администратора |

## 🔄 Как это работает

### Юзер:
`/start` → 🌐 выбор языка → ▶️ «Продолжить» → 📋 выбор тарифа →
💳 «ОПЛАТИТЬ» (реквизиты + копирование) → ✅ «Я ОПЛАТИЛ» →
📸 фото квитанции → ⏳ ожидание

### Админ:
Приходит квитанция с полной инфой о юзере и кнопками
✅ Подтвердить / ❌ Отклонить. После решения юзер получает уведомление.
`/admin` — полная статистика.

## 📁 Файлы

| Файл | Назначение |
|---|---|
| [bot.py](bot.py) | Точка входа, вся логика бота |
| [config.py](config.py) | Настройки, тарифы, реквизиты, тексты |
| [db.py](db.py) | SQLite хранилище (юзеры + платежи) |

## 📝 Заметки

- База `bot.db` создаётся автоматически; бэкапьте копированием
- Все данные переживают перезапуск (SQLite)
- Квитанции проверяются вручную — сверяйте с выпиской
- При повторной квитанции от юзера с активной подпиской админ увидит предупреждение
