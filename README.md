# Бот продажи подписки (Telegram, aiogram 3)

Воронка: выбор языка → тарифы → реквизиты оплаты → квитанция → одобрение админом.
Доступ к каналу выдаётся вручную (связь с юзером лично), бот собирает и учитывает платежи.

## 0. Важно: токен утёк!

Старый токен бота лежал в открытом коде — **обязательно перевыпустите его**:
1. Откройте [@BotFather](https://t.me/BotFather)
2. `/mybots` → выберите бота → **API Token** → **Revoke current token**
3. Новый токен вставьте в `config.py` → `BOT_TOKEN`

## 1. Установка

Нужен Python 3.12+:

```bash
pip install -r requirements.txt
```

## 2. Настройка (config.py)

Токен и админы вшиты прямо в [config.py](config.py) — .env больше не нужен:

| Константа | Что это |
|---|---|
| `BOT_TOKEN` | токен от @BotFather (см. пункт 0) |
| `ADMIN_IDS` | ID админов — уже заполнены (6552268193, 7116116919) |
| `STICKER_FILE_ID` | необязательно: стикер на /start |

Как получить `STICKER_FILE_ID`: запустите бота и перешлите ему нужный стикер
с админ-аккаунта — бот ответит `file_id`, вставьте его в `config.py`.

## 3. Реквизиты и тарифы

Редактируются в [config.py](config.py):
- `PAYMENT_DETAILS` — реквизиты карты (замените заглушку!). Попадает в сообщение и в кнопку «Скопировать».
- `TARIFFS` — список тарифов: название, срок, цена RUB/USD, `days` для учёта подписки. Добавляйте/меняйте записи — меню построится само.
- `TEXTS` — все тексты бота (RU/EN).

## 4. Запуск

```bash
python bot.py
```

## Как это работает

**Юзер:** `/start` → переключение языка RU/EN → «Продолжить» → выбор тарифа →
«ОПЛАТИТЬ» (реквизиты + кнопка копирования) → «Я ОПЛАТИЛ» → отправляет квитанцию **фото** (не документом).

**Админ:** каждой квитанцией приходит сообщение с инфо о юзере и кнопками
✅ Подтвердить / ❌ Отклонить. После одобрения юзеру летит уведомление, платёж
фиксируется со сроком действия тарифа. `/admin` — статистика: юзеры, платежи,
активные подписки (когда кому «сгорает»), последние 10 платежей.

Формат админских команд:
- `/admin` — статистика
- `/id` — ваш ID (для `ADMIN_IDS` в config.py)

## Заметки

- База `bot.db` создаётся автоматически рядом с кодом; бэкапьте её копированием.
- Язык юзера, платежи и подписки переживают перезапуск (всё в SQLite).
- Оплата подтверждается вручную: скриншоты можно подделать — сверяйте с выпиской по карте.
- Если юзер уже с активной подпиской шлёт новую квитанцию — админ увидит предупреждение.
